# runpod-comfy

Perfiles de GPU y script de arranque para el pod de ComfyUI (Seedance por API de BytePlus, preprocesado y LTX con HDR).

- `profiles.json`: GPU preferida y mínimo de VRAM por opción del menú. Datos de RunPod del 30/10/2026.
- Sin claves en este repositorio: la key de BytePlus se pasa al pod como secreto.

Pendiente: `bootstrap.sh` (rutas del pod sin verificar) y el lanzador de macOS.
